# 探索模式导航地图统一"飞船俯视图"变换设计

## 背景

探索模式右下角的导航地图（`src/components/explore/MiniMap.tsx`）此前存在两种显示模式：

- **绕飞模式（isZoomed）**：当飞船距离最近天体小于 `ZOOM_THRESHOLD_AU` 时触发。此模式下画面锚点切换到最近天体，比例尺自动放大，轨迹/预测轨迹以天体相对帧绘制，飞船不在画面中心。
- **非绕飞模式**：锚点为飞船，飞船位于画面中心，但画面不旋转（船身朝向随运动变化）。

两种模式的坐标处理逻辑分散、语义不一致，且飞船朝向不固定，不利于阅读。

## 目标

将导航地图统一为单一的"飞船俯视图"变换，不再区分绕飞/非绕飞模式：

1. **平移**：画面始终以飞船为中心，飞船恒定位于画面正中央。
2. **旋转**：画面整体旋转，使飞船船身方向在视觉上始终指向屏幕正上方（等效于飞船的俯视图）。
3. **同等变换**：导航图中所有空间内容都经过同一变换，包括各天体位置、汇合线、汇合点、速度方向线、各类轨道线、运动轨迹、预测轨迹。

## 保留行为

- **靠近天体自动放大**：`isZoomed` 判定仍然保留，但**仅用于缩小 `targetViewRange`（放大比例尺）**以及最近天体高亮、绕飞圈半径的计算。锚点不再随之切换，永远是飞船。

## 变换定义

引入单一世界→屏幕投影函数 `project(wx, wy)`，所有空间内容统一经它转换，从结构上保证"同等变换"。

设飞船世界坐标为 `(shipX, shipY)`，船身朝向单位向量 `sp.direction`，画面中心为 `(cx, cy)`，比例尺为 `scale`：

1. 平移到飞船帧：`dx = wx - shipX`，`dy = wy - shipY`。
2. 旋转：使用**平滑帧旋转量 `rot`**（见下文"延迟旋转"），使船身方向在稳定时映射到世界 +y（屏幕正上方）：
   - `rx = dx*cos(rot) - dy*sin(rot)`
   - `ry = dx*sin(rot) + dy*cos(rot)`
3. 缩放与 Y 翻转（屏幕 y 向下）：
   - `sx = cx + rx*scale`
   - `sy = cy - ry*scale`

方向向量（如速度）只做步骤 2 的旋转，不做步骤 1 的平移。

## 延迟旋转（转弯时冻结画面，稳定后平滑回正）

为避免飞船持续转弯时画面剧烈旋转，帧旋转量 `rot` 不再每帧瞬时锁定到 `π/2 - H`，而是一个**跨帧持久、带缓动的状态 `smoothRot`**：

- **转弯判定**：每帧计算航向变化率 `turnRate = |wrapAngle(H - prevH)|`。当 `turnRate ≥ TURN_RATE_THRESHOLD` 视为"正在转弯"，`stableFrames` 计数清零；否则 `stableFrames` 递增。
- **转弯时**：`smoothRot` **冻结不变**（画面/网格/天体不旋转），此时飞船船身相对冻结的画面自然地视觉旋转（船身朝向不再强制朝上）。
- **稳定后**：当 `stableFrames ≥ STABLE_FRAMES_REQUIRED` 判定为已稳定，目标 `targetRot = π/2 - H`，`smoothRot` 沿最短角差以 `ROT_LERP` 缓动逼近 `targetRot`，实现平滑回正、无生硬跳变。
- **首帧初始化**：`smoothRot = π/2 - H`（初始即对齐）。
- 参数：`TURN_RATE_THRESHOLD`、`STABLE_FRAMES_REQUIRED`、`ROT_LERP` 为可调常量；缓动使用最短角差（`wrapAngle` 归一化到 `[-π, π]`）避免绕圈。

**飞船图标朝向**：不再恒为屏幕正上方，而是反映当前航向相对当前帧的角度 `shipScreenAngle = -(H + smoothRot)`。稳定回正后该角度为 `-π/2`（朝上）；转弯冻结期间随真实航向旋转。

验证：稳定时 `rot = π/2 - H`，沿船身方向世界向量 `(cos H, sin H)` 旋转后为 `(0, 1)`，投影为屏幕向上；`shipScreenAngle = -π/2` 亦朝上，二者一致。


## 各元素处理

全部空间元素改为经 `project` 绘制：

| 元素 | 处理 |
|------|------|
| 天体位置、太阳 | `project(worldX, worldY)` |
| 运动轨迹 trail | 只存绝对世界坐标 `[x, y]`，绘制时 `project`；删除绕飞相对帧分支与 `wasZoomedRef` 清空逻辑 |
| 速度方向线 | 使用绝对船速 `sp.velocity`，仅旋转 `rot` 后绘制；不再区分绕飞相对天体速度 |
| 预测轨迹 | 绝对轨迹点逐点 `project`；删除 `predBodyState` 相对天体帧分支 |
| 汇合线 / 汇合点脉冲 | `project(rendezvous)` 与画面中心连线；脉冲绘制在投影点 |
| 目标/期望/导航轨道椭圆 | 以太阳（原点）为中心生成世界椭圆点，逐点 `project`（自动居中于太阳投影位置并随帧旋转） |
| 最近天体绕飞圈 | 圆心 = 天体投影位置，半径 = `nearestDistAU * scale`（圆形旋转不变） |
| 飞船图标 | 恒画于画面中心 `(cx, cy)`，朝向为 `shipScreenAngle = -(H + smoothRot)`（稳定回正后朝屏幕上方，转弯冻结期间随真实航向旋转） |

## 网格与 UI 元素

- **网格旋转**：按世界坐标生成等距 x/y 网格线，端点经 `project` 绘制（线宽保持屏幕像素），网格随帧旋转、随飞船平移，提供空间参考与运动反馈。
- **UI 固定（屏幕空间不旋转）**：
  - 比例尺、图例文案保持屏幕固定；图例文案统一为 `▲ 飞船 · 俯视图`。
  - 屏外天体指示箭头保持屏幕边缘固定；箭头方向由已变换后的天体投影位置计算，自然指向正确方向。

## 范围与约束

- **仅修改** `src/components/explore/MiniMap.tsx`。
- 引擎函数 `selectMiniMapVelocityVector` 因不再采用绕飞相对天体速度而不再被调用，暂保留（其单元测试不受影响），可后续清理。
- 无引擎/store 逻辑改动，故无新增单元测试需求；`.tsx` 仅承担渲染与坐标显示变换，符合分层约束。
