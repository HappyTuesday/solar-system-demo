# 探索页直接汇合导航设计

## 背景

探索太阳系页面原导航以霍曼转移和静态阶段列表为主。该模型对理论窗口、燃料和阶段顺序依赖较强，用户手动点火、熄火、偏航或延迟操作后，旧阶段容易与真实物理状态脱节。新的导航目标是：不再要求用户按霍曼转移精确飞行，而是基于当前飞船状态、目标天体轨道和飞船推力能力，持续规划一个可重新生成的直接汇合点，并用更稳定的物理指标给出阶段目标。

## 核心原则

- 导航主路径采用直接汇合策略：先加速到理想滑行速度，滑行接近汇合点，再减速到目标天体捕获允许速度范围。
- 不考虑燃料限制。导航只关心当前阶段目标是否达成，以及下一步应该怎样修正。
- 阶段含义是“阶段目标”，不是固定脚本。每轮都从当前物理状态重新评估；如果用户偏航、过燃、晚熄火或错过汇合点，导航必须能退回加速阶段或重新生成汇合点。
- 在被目标天体捕获前，导航维护一个汇合点。飞船飞向该点，目标天体也预计在同一时间附近到达该点。
- 汇合点失效时重新规划。失效条件包括：目标已接近或越过汇合点，而飞船即使按最大有效速度估算也无法及时到达；或当前有效速度/方向导致预计到达时间与目标到达时间偏差过大。实时导航指引必须优先复用当前 `navigationPlan.rendezvous`，不能在每次页面刷新或每次计算指引时重新生成汇合点；只有当前汇合点已经无汇合可能时，才允许生成新的汇合点。
- 导航指引只显示文本描述和实时指标，不提供“对准导航方向”“按指引设置推力”等快捷按钮。用户仍通过飞行控制面板执行操作。

## 计划数据结构

`NavigationPlan.method` 扩展为 `direct-rendezvous`。直接汇合计划包含：

- `rendezvousPoint`：日心 AU 坐标。
- `rendezvousTime`：目标预计到达汇合点的模拟时间。
- `targetTimeToRendezvousSec`：目标天体到达汇合点所需秒数。
- `shipIdealCruiseSpeedAUPerSec`：飞船沿汇合点方向的理想滑行速度。
- `arrivalMaxRelativeSpeedAUPerSec`：到达目标附近时允许的最大相对速度。
- `validUntil`：计划保守有效期，用于避免页面频繁重规划。
- `radialSpeedAUPerSec`：飞船速度在“飞船当前位置 → 汇合点”连线方向上的带符号分量，正值表示朝向汇合点，负值表示远离汇合点。
- `tangentialSpeedAUPerSec`：飞船速度垂直于“飞船当前位置 → 汇合点”连线的带符号切向分量。正负号由汇合点连线在黄道平面内逆时针旋转 90° 后的方向定义，用于区分横向漂移方向。

阶段列表固定表达阶段目标：

1. `脱离当前天体引力范围`：目标是相对当前绕飞天体机械能为正，或已经不处于该天体希尔球主导区。
2. `加速到汇合滑行速度`：目标是速度方向严格指向汇合点，并且当前速度大小达到或超过理想滑行速度；船身方向只用于继续加速时的操作提示，不作为阶段完成条件。
3. `滑行接近汇合点`：目标是保持有效速度和方向达标并缩短到汇合点的距离；若方向或有效速度不达标，退回加速阶段。
4. `汇合前减速`：目标是把相对目标天体速度降到捕获允许范围以下。
5. `进入目标引力范围`：目标是进入目标希尔球近旁并保持可捕获相对速度。
6. `轨道圆化`：目标是修复近点、远点和偏心率，形成安全目标绕飞轨道。
7. `到达`：目标是处于稳定目标绕飞轨道，导航完成。

## 汇合点生成

首次设置目的地或重规划时，导航根据当前时间的目标天体轨道生成候选时间：

- 估计当前飞船到目标天体的距离。
- 用飞船的保守巡航速度估计飞行时长，并限制在合理范围内。
- 在该未来时刻计算目标天体位置，作为汇合点。
- 以飞船当前位置到汇合点距离除以目标到达时间，得到理想滑行速度。
- 理想滑行速度限制在飞船可控范围内，默认上限为 300 km/s；同时保留最短 3 天到达时间约束，避免过高速度导致汇合点过近或制动窗口过短。

每轮指引重新计算：

- 目标天体距离汇合点、目标预计到达时间。
- 飞船到汇合点距离。
- 飞船当前速度在汇合点方向上的有效速度。
- 飞船当前速度相对飞船到汇合点连线的径向速度和切向速度。
- 按当前有效速度预计飞船到达汇合点的时间。
- 速度方向相对汇合点方向的带符号偏差角。

## 阶段判定

阶段判定不能只依赖瞬时距离阈值，必须优先使用更稳定的指标：

- 是否仍受当前绕飞天体束缚：相对机械能和希尔球距离共同判断。
- 是否指向汇合点：阶段完成和导航指引分支以速度方向角、速度大小、径向速度和切向速度为准；船身方向角不参与直接汇合阶段判断，也不应作为直接汇合导航指引的核心指标。
- 是否接近汇合：飞船和目标到汇合点的到达时间差、飞船到汇合点距离、目标到汇合点距离共同判断。
- 是否需要减速：预计到达汇合点时间已接近，或已经进入目标接近区但相对速度高于允许值。
- 是否捕获：目标相对机械能为负且轨道近点/远点安全。

`加速到汇合滑行速度` 的完成判定必须使用直接汇合指标：速度方向相对汇合点方向偏差不超过 2°，且当前速度大小达到或超过理想滑行速度。不能用投影有效速度的 92% 宽松阈值放行，也不能复用旧霍曼转移的 vis-viva 半长轴匹配逻辑，否则飞船还在当前天体附近绕飞或刚刚逃逸时，可能因为日心速度偶然匹配目标轨道而过早进入 `滑行接近汇合点`。

第 2、3、4 阶段都可以直接进入第 5 阶段；如果进入目标引力范围但速度过高或到达时间不匹配，则退出捕获流程并重新回到加速/汇合修正。

路线界面的当前阶段必须来自 `direct-rendezvous` 计划的实时阶段完成判定，而不是旧火星专项指引的静态保护逻辑。`脱离当前天体引力范围` 阶段在飞船相对当前绕飞天体机械能为正，或 `getOrbitingBodyId` 已切换到 `sun` 时完成，并推进 `activePhaseIndex`，使右侧导航路线立即显示下一阶段目标。

导航阶段推进只更新 `activePhaseIndex` 和路线提示，不自动熄火、不自动切档、不自动修改推力大小。用户通过飞行控制面板手动熄火或切换 N 档；导航只能通过文字指标提示“应熄火/滑行/减速”，不能替用户改写实际飞控状态。

## 导航指引显示

右侧导航指引保留文本和数值，不显示快捷操作按钮。必须实时显示：

- 飞船速度方向与汇合点方向之间的带符号角度偏差。
- 按当前速度飞行到汇合点所需时间，仅使用指向汇合点方向的有效速度计算。
- 相对飞船到汇合点连线的径向速度，正值表示朝向汇合点，负值表示远离汇合点。
- 相对飞船到汇合点连线的带符号切向速度，用于判断横向漂移方向和是否需要修正。
- 当前有效速度。
- 理想滑行速度。
- 飞船按当前有效速度到达汇合点所需时间，以及目标天体预计多久到达汇合点。两项必须在直接汇合导航中持续显示，直到飞船进入目标天体引力范围并转入捕获/圆化流程。
- 当前阶段目标和用户应该执行的文本说明。
- 直接汇合导航指引的文案和操作分支必须关注飞船的飞行方向与汇合点方向的夹角。当速度方向夹角偏大时，提示修正飞行方向；当速度方向达标但速度不足时，提示加速；当接近汇合点或目标相对速度过高时，提示减速。船身方向可快速调节，因此不作为直接汇合指引是否“转向”的判定依据。
- 导航指引和飞行面板仍必须显示船身方向相对参考方向的带符号夹角，作为用户姿态反馈；正负号沿黄道平面区分船头偏在参考方向的哪一侧，且该夹角不能驱动直接汇合阶段完成或直接汇合指引分支。
- 减速指引必须利用飞行控制面板的 `R` 档反推能力：需要降低当前速度或目标相对速度时，导航推荐船头保持当前速度方向或目标相对顺行方向，并使用 `R` 档产生反向推力；不应要求用户先把船头大幅调到逆行方向再用 `D` 档加速。
- `汇合前减速` 是直接汇合导航的一部分，目标是让飞船在汇合点附近、规定时间窗口内以足够低的目标天体相对速度抵达。对火星任务而言，火星相对速度是该阶段的关键速度指标，但在进入火星引力范围或形成火星束缚轨道之前，界面仍应显示为 `汇合前减速`，不应提前切换为独立的 `火星相对制动` 局部阶段。

## 时间倍率与档位语义

探索页物理推进必须始终按 `frameDt * timeScale` 推进模拟时间。开启推力时可以减小积分子步长以保证稳定性，但不能把整帧模拟时间钳到固定小值，否则时间倍率在点火时会表现为失效。

推力滑块表示可用推力大小，档位表示实际推力方向。`D` 档使用滑块值产生正向推力，`R` 档使用滑块值产生反向推力，`N` 档表示没有任何实际推力；即使滑块不在最左侧，N 档也不能产生物理加速度、点火声效、推力火焰或阻止无推力时间跳转。所有判断“是否正在点火”的逻辑必须以实际体坐标推力向量和推力大小共同判断，而不能只看 `thrustMagnitude > 0`。

直接汇合导航存在时，飞行控制面板额外显示 `T` 档（切向修正档）。`T` 档不是普通手动档，只在 `direct-rendezvous` 导航阶段显示；挂入后系统每帧按当前飞船到汇合点连线重算带符号切向速度，并自动接管飞船姿态、体坐标推力和推力大小。`T` 档必须把船头指向切向速度的反方向，使用体坐标正向推力，并把推力大小限制在较低范围内，使推力方向始终垂直于飞船到汇合点的径向连线，从而不直接改变径向速度，只把切向速度慢慢推向 0。`T` 档不能启用反推或沿汇合线方向执行减速；若切向速度绝对值降到近零阈值，或切向速度符号相对挂档时发生过零，系统自动回到 `N` 档并清空实际推力。

## 汇合点可视化

当直接汇合计划存在且包含 `rendezvous.point` 时，探索页必须在两个视图中同时显示汇合点：

- 主视图：在 Three.js 场景中创建一个跟随 `rendezvous.point` 的汇合点标记。标记使用发光核心和多层扩散脉冲环，始终以脉冲形式提示用户要飞向哪里。标记只是导航提示，不参与碰撞和物理。
- 导航图：在 Canvas 2D 俯视图中绘制从飞船到汇合点的绿色虚线、汇合点核心和多层扩散脉冲环。汇合点不在当前视野内时，仍按当前导航图坐标投影绘制，后续可扩展为边缘指示。
- 脉冲参数由 engine 层纯函数生成，保证主视图与导航图节奏一致，组件只负责把半径/透明度映射到 Three.js 或 Canvas 绘制。
- 若导航计划为空、不是 `direct-rendezvous`，或没有汇合点，则两个视图都隐藏汇合点标记。
- 导航图中的速度方向箭头必须与导航指引的“速度方向偏差”使用同一参考系。直接汇合路线是日心汇合目标，因此即使导航图处于近天体缩放视图，速度箭头也使用飞船日心绝对速度；普通绕飞或非直接汇合路线仍可在缩放视图中使用相对最近天体速度，避免局部绕飞视图失真。

## 文件职责

- `src/engine/navigation.ts`：新增直接汇合计划、汇合指标、阶段目标评估和实时指引逻辑。继续保留旧霍曼函数以兼容既有测试和历史文档。
- `src/engine/navigationVisual.ts`：提供汇合点脉冲动画参数、导航图速度箭头参考系选择的纯函数。
- `src/stores/spaceshipStore.ts`：设置目的地和重规划时使用直接汇合计划。
- `src/components/explore/PhaseGuide.tsx`：删除快捷按钮，只渲染实时指引文本和指标。
- `src/components/explore/Dashboard.tsx`：阶段列表展示新的阶段目标和汇合摘要。
- `src/components/explore/MiniMap.tsx`：继续绘制目的地轨道；直接汇合计划下绘制飞船到汇合点的方向线和脉冲目标点，不再把活动阶段误画为霍曼转移椭圆。
- `src/components/explore/ExploreCanvas.tsx`：在主 Three.js 场景中渲染汇合点发光核心和扩散脉冲环。

## 验证

- 单元测试覆盖直接汇合计划生成：计划方法为 `direct-rendezvous`，阶段目标为新七阶段，汇合点、目标到达时间、理想滑行速度均有效。
- 单元测试覆盖汇合指标：速度方向角保留正负号；径向速度为相对汇合点连线方向的带符号分量；切向速度为垂直该连线的带符号分量；有效速度只取正向径向分量；到达时间在有效速度为零或反向时为无穷。
- Store 单元测试覆盖 `T` 档：直接汇合计划存在时可挂入切向修正档，系统自动把船身姿态调到切向速度反方向，使用体坐标正向推力并自动设置较低推力大小；该推力方向与飞船到汇合点连线正交，不能产生径向分量；切向速度接近零或发生过零时自动回到 `N` 档并清空实际推力。
- 单元测试覆盖阶段回退：滑行中方向或有效速度不达标时，实时指引回到加速阶段。
- 单元测试覆盖汇合点脉冲参数：半径随时间扩散，透明度随扩散衰减，并保持固定层数。
- 组件测试覆盖 `PhaseGuide` 不再渲染快捷操作按钮。
- 运行导航相关 vitest，并用 `npm run build` 验证类型和生产构建。
