行星轨迹设计方案

为正在运动的天体添加尾迹可视化，帮助观察轨道运动

设计关键词

尾迹长度 颜色/透明度 性能影响 可配置性

A — 单色实线尾迹

采样天体历史位置，用 Line 绘制固定长度尾迹，颜色与天体一致，统一透明度。

Pros

  • 实现简单
  • 性能极好
  • 轨道形状一目了然

Cons

  • 缺乏运动方向感
  • 尾部截断生硬

B — 渐变淡出尾迹

沿历史位置绘制多条短线，越旧越透明、越细，自然淡出。

Pros

  • 有速度感和方向感
  • 视觉效果优雅

Cons

  • Draw call 数较多
  • 透明度排序有 z-fighting 风险

C — 点阵淡出尾迹

等时间间隔放置小球体，越旧的点越小越透明。

Pros

  • 三维空间感强
  • 材质表现丰富
  • 方向感明显

Cons

  • 小球体数量多影响性能
  • 间距需精心调整

D — 实线 + 渐变透明度

用 Line 绘制，但通过顶点颜色或 shader 实现头到尾从亮到暗的渐变。

Pros

  • 一个 draw call
  • 性能最优
  • 视觉效果完全可定制

Cons

  • 需要 VertexColors 或 custom shader
  • Oldest-segment 截断不明显（可加总长限制）
